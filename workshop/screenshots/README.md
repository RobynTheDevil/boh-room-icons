# Screenshots

Images for the Steam Workshop listing. Drop them here.

Steam shows them in filename order, so name them for the order you want: `01-...`,
`02-...`. The first is the one that appears beside the item in search results and in a
subscriber's library, so it wants to be the clearest example of icons on the map rather
than the prettiest shot of the house.

`cover.png` in the mod folder is a separate image and is not one of these. It is the
listing's preview thumbnail.

Shoot at the game's own resolution and do not scale them up. Steam accepts JPG and PNG up
to 2 MB each.
